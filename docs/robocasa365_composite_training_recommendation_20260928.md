**建议优先补齐关键操作能力，并用对照决定下一轮训练改动。**

截至 2026-09-28 04:36 UTC 的云查询，四卡主任务仍在运行，Composite 新增训练到 10,000 步，正在进行 320 次开发评估。已完成 153 次、成功 0 次；这不是完整 10k 结果。2k 的完整结果为 0/320。10k 权重已完成独立 EFS 备份和读回核验。既定的 25k、50k 训练与评估继续执行。

Atomic18 50k 的完整成功率为 279/1,800（15.5%）。其中五个 PickPlace 搬运任务合计 21/500（4.2%）：台面到柜子 7、台面到炉灶 2、抽屉到台面 1、水槽到台面 3、吐司机到台面 8，各 100 次。这个起点的搬运能力仍弱。已分析的 Composite 取面包和取吸管案例又失败在启动设备、打开抽屉、抓取之前，因此优先级应包括基础操作学习，不能仅归因为复合任务流程长。

保存动作链审计没有发现顺序、尺度、12D 重排或 delta/absolute 合同错误，但这不能单独排除实时相机输入、场景分布等问题。8 条保存策略轨迹的精确重放也不能替代旧专家 demo 接触漂移的修复。

三任务命令对照已完成：120 条不同演示、240 个窗口、960 个动作片段，独立复算通过。取面包的切换窗口关闭召回，训练由 2k 的 16.9% 降至 10k 的 5.6%，验证由 25.0% 降至 11.3%；取吸管的关闭召回上升，但误关闭也增加。模型没有随着训练步数增加稳定学好这些命令。所选训练窗口的精确输入帧在实际前 10k 抽样中多数未出现，不能据此认定它已充分拟合训练集。

**下一项优先验证起始／命令切换阶段采样。** 当前证据支持这个实验的优先级，没有证明采样是唯一根因。具体按以下顺序推进：

1. **保留当前四卡基线，完整评估和保存权重。** 使用完整的 10k/25k 开发结果选择后续策略，50k 的 1,600 次最终评估保持独立。新增算力优先支持有明确比较对象的实验。
2. **从同一 Composite10k 权重做两路小规模对照。** 两路都用全部 7,271 条训练演示，保持 806 条验证演示隔离、同归一化、同有效 batch、同动作学习率和预算，均重置优化器及学习率计划。A 路保持任务均衡、均匀帧采样；B 路采用 50% 普通帧、25% 各演示前 16 帧、25% 前 8 步包含 mode/gripper 切换的帧。任务抽样序列配对，训练噪声配对，只有帧抽样策略不同。候选比例不是已证明的最优比例。两路第一阶段各新增 2,000 步；空闲算力允许时各用一张卡，原四卡主线保持。排队前完成 CPU 更新、保存恢复和配置检查，获取 GPU 后先短验收显存与恢复，再进入完整预算。
3. **先证明具体操作改善，再扩大新分支。** 使用同一批开发场景，先对取面包、取吸管、搅拌各做 20 次／路的配对筛查，同时复查独立验证命令拟合。检查漏关与误关、底盘模式两类错误、平移／旋转误差，以及官方状态能支持的启动设备、开抽屉、抓取等阶段事实。阶段判据必须另行验收，不能用命令切换标签冒充物理事件。短筛查不能代替完整成功率；有一致收益的候选再扩展到 16 任务开发评估，最终仍保留独立的 16×100 次测试。若改善只体现在 loss 或更多关闭命令，不据此扩大训练。

后续分支用于缩小原因范围，单个离线指标不能唯一确定根因：

| 发现 | 优先实验 | 判断收益的依据 |
| --- | --- | --- |
| 新采样对照后，反复抽到的训练窗口仍拟合差 | 用少量原训练窗口做有界拟合检查，检查梯度、损失分量与可用视觉信息，再安排独立视觉适配对照 | 明确的窗口曝光次数、训练拟合及未参与小样本更新的验证表现；小样本结果不是多任务成功率 |
| 训练拟合较好，验证或新场景明显差 | 检查实际相机输入与场景差异，再做冻结视觉／部分联合训练对照 | 同起点、同数据、同场景的闭环收益，兼顾阶段指标 |
| 录制窗口预测尚可，闭环仍偏离 | 对照实时图像构造，并单独比较执行前 8 步与更短执行段，检查控制模式切换 | 开发场景下的真实接触、抓取和任务成功，单列协议与额外推理代价 |

**视觉适配作为下一项独立对照。** 采样实验继续训练 State Encoder、Action Encoder/Decoder、Action DiT，Video DiT/VAE/Qwen 保持冻结。若证据支持视觉适配，候选是额外解冻 Video DiT blocks 16/17，Qwen 和 VAE 继续冻结。公开实现对动作条件 hidden 使用 detach，仅设置 requires_grad 不会让动作 loss 更新视觉；必须配合真实未来视频和视频 flow matching loss。论文视频 1e-5、动作 1e-4 的学习率可作为参考，实际设置仍需预检。这个视觉实验尚未提交，也没有验证闭环收益。

全量动作统计给出两个需要落实的细节：当前 16 任务数据并非全固定底盘，必须保留并检查完整 base/mode；按现有任务均衡采样，关闭命令比例约 44.4%，但未来执行前 8 步含夹爪切换的窗口约 3.92%。不能简单把“多预测关闭”当成修复方案。以上是数据统计，不是切换监督不足的因果证明。

**准备状态：数据预检已通过，新增对照尚未训练。** 28 项单元检查通过；真实 Composite10k 动作分支初始化、247 张量加载、新优化器为空已通过。全部 7,271 条训练 parquet 的阶段池经独立算法复算一致，验证演示未参与建池；真实 16 任务 adapter 的 16,000 次两路抽样保持相同任务序列和 RNG 终点，恢复后逐值一致。48 个真实样本覆盖每任务起始／切换／结尾，图像、状态、动作、mask、原动作反归一化均通过。上述数据预检不代表新训练前后向、CUDA 或完整 checkpoint 恢复验收通过。新 GPU 任务数仍为 0。

现阶段最有价值的结果是区分“基础动作没学好”“视觉与场景泛化不足”“闭环执行偏离”。当前证据尚不能保证增加训练步数或解冻视觉就能提高成功率。
