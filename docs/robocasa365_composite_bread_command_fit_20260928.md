**取烤面包的命令预测诊断：优先检查起始与切换阶段的训练覆盖**

本轮已完成 GetToastedBread 的离线配对预测、4/16 次积分对照，以及 Composite 前 10k 步实际采样重建。各项均通过独立复算。没有进行优化器更新或新增闭环策略试验，以下召回率不是任务成功率。

取面包的样本沿用此前固定选择的 20 条训练演示、20 条验证演示，各取起始与首次持续关闭命令前的窗口。它们是三任务 120 条演示完整诊断的一部分，没有新增或按预测结果筛选演示。复用已完成的 80 个 CPU 视觉特征，两个噪声种子配对预测；全量诊断仍在运行，待其完成后还要逐值核对缓存计算与完整计算的一致性。

**10k 在这组切换窗口中仍大量漏判关闭命令。** 切换窗口的执行前 8 步，GT 前 4 步张开、后 4 步关闭。每个划分有 20 条独立演示、40 个相关预测片段、160 个应关闭的命令时刻。

| 权重与推理设置 | 训练：关闭命令召回 | 验证：关闭命令召回 |
| --- | ---: | ---: |
| Composite 新增 2k，4 次积分 | 27/160，16.9% | 40/160，25.0% |
| Composite 新增 10k，4 次积分 | 9/160，5.6% | 18/160，11.3% |
| 同一 Composite 10k，16 次积分 | 13/160，8.1% | 22/160，13.8% |

噪声重复和相邻命令不是新的独立演示。10k、4 次积分的切换窗口总体夹爪错误率为训练 48.44%、验证 47.19%；该组目标正负类各半，一直预测张开的错误率为 50%。这些数字只刻画命令拟合，不刻画抓取、接触或吐司机启动。特别是，漏判关闭不能单独解释为什么拨杆没有压下。

检查完整 16 步预测后，10k 的训练切换窗口只有 7/40 个预测片段曾发出关闭命令，验证为 13/40；执行前 8 步分别为 3/40、5/40。因此存在部分延迟，但不能把漏判全归为“关闭命令落在未执行的后 8 步”。

**增加积分次数没有在这组样本中解决问题。** 4 次变为 16 次只改变动作推理积分数，权重、特征、状态、目标和初始噪声均配对。关闭召回略变，但机械臂平移命令 MAE 在训练切换窗口由 0.1570 增至 0.1744，验证由 0.1233 增至 0.1403。这里的误差是 [-1,1] 控制量的误差，不是米。基于逐演示的探索性配对区间也支持平移误差上升；尚未进行对应闭环试验，不将其外推为所有场景下 16 次积分都更差。当前没有因此修改正式评估设置。

4 次积分的零平移命令基线，训练切换窗口 MAE 为 0.1508，验证为 0.1121。模型在该离线指标上尚未优于这一参考；这不意味着机器人静止能完成任务，也不能证明视觉或动作分支中哪个环节是唯一原因。

**需要区分训练演示和真正抽到的输入帧。** 我们用运行中的冻结采样代码重建 Composite 本地 10k 步，并另用原始 episode 元数据、整数抽样和累积计数独立重建。两路所有帧计数一致，四个 rank 的随机数终点都与真实 10k 权重一致；Atomic 50k 的历史抽样没有混入。

| 实际覆盖 | Composite16 全部 | GetToastedBread |
| --- | ---: | ---: |
| 训练演示 | 7,271 | 455 |
| 至少抽到一次的演示 | 7,271 | 455 |
| 训练输入窗口抽样次数 | 640,000 | 39,908 |
| 不同输入帧覆盖 | 597,650 / 5,403,990，11.06% | 38,558 / 588,266，6.55% |
| 首帧曾被抽到的演示 | 931 / 7,271 | 37 / 455 |
| 曾作为未来动作目标的不同帧 | 4,348,499 / 5,403,990，80.47% | 387,950 / 588,266，65.95% |

所选 20 个取面包训练切换窗口中，仅 2 个精确输入起点被抽到过，各一次；其前后 8 帧邻域有 16/20 个窗口曾被抽到，累计 28 次。前 8 步的 160 个动作目标中，127 个曾在其他重叠窗口中接受监督。因此既不能称它们为“已经反复拟合的训练输入”，也不能说这些动作标签完全没有训练过。覆盖率本身不证明收敛程度。

这些证据把下一步优先级收窄到：检查起始与命令切换窗口的有效学习，并准备同起点、同任务划分、同训练预算的采样对照。候选应保留所有 16 个任务和普通阶段样本，提高起始／mode 与 gripper 切换邻域的采样，保持完整 12D action、原统计与验证隔离。具体比例和提交方案等待三任务诊断汇总后确定；尚未启动这项新训练。

这并未排除冻结视觉特征限制、数据／实时图像差异或其他优化问题。现有四卡主线、10k/25k/50k 评估和权重备份继续；Video DiT 的部分联合训练仍作为独立候选。旧专家 GT 接触漂移没有被本轮离线计算解决，历史原 16 演示 step2000 的指定 A/B 也没有被本轮实验替代。
